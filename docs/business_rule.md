
| ID | Regola | 
|----|------|
| BR-01 | Il saldo di un utente non è mai negativo e cambia soltanto per effetto di checkout, rimborso e operazioni dell'amministratore. |
| BR-02 | La giacenza di un prodotto non può essere mai negativa. |
| BR-03 | La percentuale di un codice sconto è un intero tra 5 e 25. |
| BR-04 | Un ordine usa al più un codice sconto. |
| BR-05 | Il totale di un ordine deve essere maggiore di zero. |
| BR-06 | Ogni riga del carrello ha quantità maggiore di zero e righe dello stesso prodotto sono sommate. |
| BR-07 | La valutazione di una recensione è un intero da 1 a 5. |
| BR-08 | Il prezzo di un prodotto è maggiore di zero. |
| BR-09 | Se un utente smette di esistere, smettono di esistere anche i suoi ordini e le sue recensioni  |
| BR-10 | Se un utente rimborsa o annulla un ordine, l'intero ammontare dell'ordine gli viene restituito |
| BR-11 | Un utente può recensire un prodotto solo se esiste un ordine associato a quell'utente contenente quel prodotto nello stato "Consegnato/Rimborsato"|
| BR-12 | Un utente può recensire un singolo prodotto al più una volta |
| BR-13 | Alla registrazione ogni utente ha ruolo "Standard" |
| BR-14 | L'indirizzo email di ogni utente deve essere univoca e in formato valido: nome@dominio.dominio |
